# AXI-011：用户授权的中文工作区

Status: `approved`
Date: 2026-08-28
Owner approval: 产品所有者明确要求插件启用时不得自动创建工作区；必须先启动本地工作台，由用户手动选择位置后创建，并采用中文目录规范。

## 决策

- 安装、启用、加载 MCP、调用 `get_started` 和打开本地工作台都不得创建 `AutoXEO_Workspace`。
- 未配置工作区时，本地服务以只读的“待选择”状态运行。
- 用户在工作台中选择父目录并再次点击“创建工作区”后，才创建 `<父目录>/AutoXEO_Workspace`。
- 用户可以显式连接已有 `AutoXEO_Workspace`；旧版英文目录只做兼容读取，不在后台静默迁移或改名。
- 新建工作区的所有业务可见目录和模板文件使用中文；`.autoxeo` 保留为隐藏的机器状态目录。
- 路径选择和创建是本地动作，不登录、不连接 Provider、不扣 Credit，也不修改 Cloud。

## 验收

- 空白配置下启动 MCP、调用 `get_started`、调用 `get_workspace_context` 和打开工作台后，默认 Documents 目录不出现 `AutoXEO_Workspace`；
- 工作台先选择父目录，再显示将创建的完整路径，最后由用户明确点击创建；
- 新建工作区 manifest 标明 `layoutLanguage=zh-CN`，所有业务可见目录均符合本规范；
- 工作区未创建时，依赖本地文件的工具返回 `WORKSPACE_NOT_CONFIGURED`，账号状态与工作台仍可读取；
- 已连接的旧工作区不被自动迁移或删除；
- Skill、README、MCP 描述、UI、单元测试、smoke 和发行物使用同一契约。
